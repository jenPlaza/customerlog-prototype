# Community Wellness Customer Log Prototype

The Community Wellness Customer Log is an innovative, fully functional database
and registry system built using HTML, CSS, and Vanilla JavaScript, seamlessly
integrated with Google Sheets via custom Apps Script automations. Crafted from
conception as a collaborative effort with Gemini AI, which contributed in the
development of the backend code for Google Apps Script and table formulas, this
project is meticulously developed to automate data workflows, streamline
administrative tracking, and ensure smooth, stress-free pantry operations. The
intuitive dashboard is specifically engineered for high accessibility and ease
of use by both volunteers and the elderly. It features tables that automatically
expand, dynamically reports on pantry activity without manual data entry,
optimizes the overall user experience, and much more. By utilizing the Google
Sheets API, data is fetched and displayed in real time on an Active Pantry
Orders queue web page, allowing each order to be individually viewed, tracked,
and fulfilled by pantry personnel / volunteers.

As a volunteer at St. Andrew's Catholic Church Outreach program, I firsthand
experienced the urgent need to transition from traditional paperwork to a
digital framework to sustain rigorous data accountability. This low-maintenance
system provides two distinct ways to search raw, day-to-day logging data: a Live
Search Filter for quick, over-the-phone name lookups, and an Active View Search
that maps a comprehensive history of customer completion dates.

The background engine coordinates three main data components:

- The Roster Tab: Allows operators to seamlessly register brand-new customer
  profiles.

- The Log Tab: Tracks chronological, day-to-day entries for both new and
  returning visitors.

- The Pantry List: Houses customer grocery preferences, which are fetched
  directly into the order viewer for accurate volunteer packing.

The final structural feature of this workspace is an automated Reporting
Dashboard that isolates and tallies daily new registrations directly from the
Roster source, tracks pantry visit completions, and aggregates the total number
of household members served.

## About the Outreach Community Pantry at St. Andrews Catholic Church

The Outreach Community Pantry, at St. Andrews Catholic Church, provides local
families with essential groceries, alleviating the stress of food insecurity.
The feeding kitchen simultaneously offers hot, nutritious meals and a welcoming
space for unhoused neighbors. By bridging these vital resource gaps, they
empower individuals with a more sustainable lifestyle.
